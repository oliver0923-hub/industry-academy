# Lesson 00 敘事架構與證據需求

原正式課名保留：學院導覽：何謂產業？SIC、NAICS、台灣行業統計分類、證交所分類的差異。候選稿以「什麼是產業」作閱讀標題，不改課號或網站目錄。

讀者：沒有經濟、會計與管理先備知識的一般讀者。核心成果：能從生活交易辨識生產活動，分開企業／行業／產品市場／價值鏈，並讀懂一組有年份與口徑的產業數字。

| 節 | 敘事問題 | 證據與取捨 |
|---|---|---|
| S01 一份早餐背後 | 為何付錢給一家店，卻涉及許多產業？ | 明示假設教學情境，不編造真實人物與供貨商。 |
| S02 企業與活動 | 公司、場所與產業為何不是同一件事？ | TW12 PDF7–9；台積電1998原始年報。 |
| S03 市場與替代 | 分類相同就必然競爭嗎？ | FTC2023處理原則第2–7點；飲料例明示假設。 |
| S04 分類制度 | SIC、NAICS、ISIC、台灣及TWSE為何並存？ | NAICS2022 PDF15–16；UN ISIC；TW12 PDF4,6–9；TWSE2025要點1–5。 |
| S05 價值鏈與協調 | 為何有分工，也有企業內部整合？ | Tyson2024 PDF4；Coase1937 pp388–394；Gereffi等2005 pp83–87,97–99。 |
| S06 數字與價值 | 收入、附加價值與利潤差在哪裡？ | DGBAS113年年報附錄一PDF2–3；零售2024表2–3；純假設四環節數值。 |

| S09 真實企業窗口 | 台積電與Walmart揭露哪些分工轉折？ | 台積電1987–1998、Walmart1962–1991與FY2024；限制公司自述與成功者偏誤。 |
| S10 閱讀產業 | 如何帶著問題而不是標籤讀下一堂？ | 回到早餐；情境／5題／術語／原始來源／原課號相關課程。 |

定向新增只處理分類歷史、相關市場、官方附加價值與結構資料。放棄本課不需要的全球企業排名與產業預測。EU市場界定下載受限，改用已取得且核讀的台灣FTC原始規範；不把搜尋摘要當正式全文。

四關審查分開記錄：事實；推論；初學者閱讀；第二輪批判性再讀。單一編者第二輪再讀不等於獨立審閱者，第四關若無獨立審閱者仍列待完成，不因候選稿完成而自動放行。
