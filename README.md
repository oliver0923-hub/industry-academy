# Industry Academy｜全球產業、台灣經濟與企業策略研究學院

這是 Industry Academy 的獨立網站與課程內容儲存庫。

## 教學目標

從全球產業概況出發，連結台灣產業環境、產業價值鏈、代表企業、策略挑戰與學術研究。

## 課程規劃

依據《Industry Academy Master Project Instructions v2.0》，規劃第 00–49 堂，共 50 堂課，並支援隨選產業加選課。

## 預計網站技術

- React + Vite
- GitHub Pages（後續部署設定）
- 繁體中文內容
- 互動式單人管理決策模擬

## 專案界線

此儲存庫與 M&A Academy 獨立，不使用 Railway。網站尚未建立或部署。
